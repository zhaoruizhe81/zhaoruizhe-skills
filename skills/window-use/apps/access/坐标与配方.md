## 配方

### R1 建库建表（零 GUI，A8）
`acc.boot` 不需要；直接 `win32com.client.Dispatch("DAO.DBEngine.120")` →
`CreateDatabase(path, ";LANGID=0x0804;CP=936;COUNTRY=0")` → `acc.mktable/mkrel/ins/set_colwidth` →
重开库 `SELECT Count(*)` 校验落 txt。字段类型：3=Integer 4=Long 5=Currency 8=Date 10=Text(+Size) 11=OLE。
日期一律传 "YYYY/MM/DD" 字符串（A4，防 8h 偏移）。

### R2 信任位置（A9）
`acc.trust(目录)`（subprocess list 传参，尾反斜杠安全）。**别用 os.system**——
cmd /c 引号配对会吃掉 `\"` 尾反斜杠，注册表值会被写成 `目录" /f`（实付 1 轮）。

### R3 查询实验标准流（第 13 章型）
DAO `acc.create_query`（幂等）→ `acc.boot` → `acc.focus` →
`acc.shots_design_result(app, "Q1", "q01", shot, log)`。
动作查询（生成表/删除/更新/追加）：boot 时 `warnings=False` → 设计截图 →
`OpenQuery(name, 0)` 静默执行 → `OpenTable(表名, 0)` 截 before/after。
**参数查询**：A6 两段式——触发 OpenQuery 预期超时 → killpw.cmd 杀 pythonw（对话框留存）→
纯 GUI 脚本 paste_at 参数值 + 点确定。

### R4 窗体实验标准流（第 14 章型）
`acc.boot` → `acc.del_object(app, AC_FORM, "F1")` → `frm = acc.dyn(app.CreateForm())` →
设 RecordSource/Caption/Width → `app.CreateControl(tmp, 类型, 0, "", "", L, T, W, H)` →
绑定字段 `tx.ControlSource = 字段`（列头需控件的再 `tx.Name = 字段`）→
`acc.save_as(app, tmp, "F1")` → `DoCmd.OpenForm("F1", 0)` → sleep 2.2 → shot。
事件按钮：`acc.add_events(app, "F8", [("cmdNext", "DoCmd.GoToRecord , , acNext"), ...])`。
数据表/分割窗体列头空白 → `acc.attach_headers`（A12）。
子窗体：`CreateControl(tmp, AC_SUBFORM,...)` → `SourceObject`/`LinkMasterFields`/`LinkChildFields`。

### R5 图表窗体（全 GUI 向导，程序化嵌入已死——A11 全坐标）
1. COM 建干净窗体（仅标签），保存，`OpenForm(设计)`，脚本末尾 sleep(300) hold 会话
2. pt.py 超时返回 → killpw.cmd 杀 pythonw（模态对话框保护 Access 存活）
3. 纯 GUI 脚本：点控件库下拉→图表→画布拖拽 (480,360)→(930,610) → hold
4. 一条龙 GUI 脚本走完 5 页（**全程不再杀 pythonw**，中途杀=图表被静默丢弃）：
   查询radio→Q5→下一步→>>→下一步→下一步(sleep 50 等渲染)→下一步→标题框 ^a+delete+粘贴→
   完成→sleep 9→Ctrl+S→sleep 4→视图(40,125)→窗体视图(99,182)→sleep 5→shot
5. 完成后拖拽画布残留控件要 VBE 注入 DeleteControl 清理（`acc.run_vba`）
6. 标题在向导标题页一次贴对（`^a`+`delete` 清预填）；事后外部 COM/VBA 改 ChartTitle **均不持久**

### R6 模态对话框通用（A6）
两段式：COM/GUI 触发（预期超时，pt.py --timeout 调小）→ killpw.cmd → 纯 GUI 脚本
（paste_at/坐标点击，**勿再 boot_access**）→ 截图。
