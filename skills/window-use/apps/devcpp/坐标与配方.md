# Dev-C++ 5.11 坐标与配方（windowpc 1920×1080 实测，2026-11-02）

## 环境事实
- exe：`C:\Program Files (x86)\Dev-C++\devcpp.exe`（可带源文件参数启动：`Popen([exe, r'C:\...\xxx.c'])`）
- 编译器：TDM-GCC 4.9.2 64-bit Release；单文件编译输出 exe 到源文件同目录
- 界面：中文；源文件编码 ANSI(GBK)；行数/长度看状态栏

## 快捷键
F9=编译，F10=运行，F11=编译并运行；^S 保存，^O 打开文件，^A/^V 编辑器内覆盖粘贴。

## 窗口标题模式
- 主窗口：`C:\...\xxx.c - Dev-C++ 5.11`；匹配用 `xxx.c - Dev-C++`（防 MDI 子窗口歧义，踩坑 D7）
- 运行中：`xxx.c - [Executing] - Dev-C++ 5.11`（踩坑 D6）
- 控制台：`C:\...\xxx.exe`（ConsolePauser）

## 配方 A：打开源文件（已有实例）
```
raise_topmost('当前文件名 - Dev-C++') → hotkey('ctrl','o') → sleep 1.5
→ paste_at(985,583, r'C:\Users\...\xxx.c') → enter → sleep 2
→ raise_topmost('xxx.c - Dev-C++') → shot
```

## 配方 B：编译并留证（一个原子步）
```
raise_topmost('xxx.c - Dev-C++') → click(700,400) → press f9 → sleep 3.5 → shot
```
日志看「错误: 0 / 警告: 0 / 输出文件名 / 编译时间」。

## 配方 C：运行+交互+关窗（一个原子步）
```
raise_topmost('xxx.c - Dev-C++') → press f10 → sleep 2.5
→ [输入: 数字 typeln('15 4')；中文 set_clip+hotkey ctrl+v+enter]
→ sleep 1.5 → shot(控制台) → press enter(关控制台) → sleep 1.2
```

## 配方 D：编辑器内容替换（磁盘文件被外部修改后，踩坑 D5）
```
click(700,400) → ^a → set_clip(新源码全文) → ^v → ^s → (可能弹 Confirm 点 Yes)
```

## 配方 E：源文件流水线（Mac → PC）
1. Mac 写 UTF-8 源码 → `text.replace('\n','\r\n').encode('gbk')` 落盘
2. `ssh windowpc "mkdir -p ~/Documents/实验目录"` → ssh-skill upload（home 相对路径）
3. 控制台输出中文 = 源码 GBK 字面量 + GBK 控制台，天然对齐

## 中文卡片/表格对齐配方
- 每行统一结构：`|`+空格+内容(固定格数)+空格+`|`；边框 `+` + N 划 + `+`
- GBK 1 汉字=2 格、全角标点=2 格、ASCII=1 格；printf %-Ns 按字节补齐=按列对齐
- 验证：渲染截图放大读边框列；像素扫描（numpy 找每行最右亮像素）可定量
