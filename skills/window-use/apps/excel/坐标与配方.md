- 采集：`-f gdigrab -framerate 30 -i desktop -c:v libx264 -preset veryfast -crf 23 -pix_fmt yuv420p`
- **停止前必须 `-flush_packets 1`**，否则 terminate/taskkill 后 ts 为 0 字节（缓冲全丢，实测两次）

- Popen 加 `creationflags=0x08000000`（CREATE_NO_WINDOW）防黑框抢焦点
- Game Bar：此 PC 注册表无 AppCaptureEnabled，Win+Alt+R 无效，别浪费时间

## 配方：优雅关闭 Excel（防文档恢复面板）

pywinauto `win.close()` → 弹保存对话框（标题同名）→ descendants(control_type="Button") 找「不保存」点击；
找不到就 `type_keys('%n')`（Alt+N）。强杀 taskkill /F 会触发下次打开的文档恢复面板，污染录屏。
