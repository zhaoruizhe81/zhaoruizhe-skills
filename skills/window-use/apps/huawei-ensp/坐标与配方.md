## 配方

### R1 打开拓扑（文件关联式，N3——唯一可靠方式）

```python
import subprocess, time
for exe in ("eNSP_Client.exe", "eNSP_Switch.exe", "eNSP_VBoxServer.exe"):
    subprocess.call('taskkill /F /IM %s' % exe, shell=True)
time.sleep(2)
subprocess.Popen('cmd /c start "" "D:\\20zy\\eNSP考试拓扑\\企业园区网络设计.topo"', shell=True)
```
然后**只轮询不交互**（N4）：每 30s shot 一次，直到标题栏中央出现拓扑名/状态栏"总数: 5"。
冷启动预算 5 分钟。脚本内 `assoc .topo` 应输出 `topofile`。

### R2 启动全部设备

### R3 交换机验证（telnet 平行通道，N7——首选，别开 GUI 控制台）

设备启动后，Mac 直接：
```bash
ssh win135 'python - <<PY
import socket
s=socket.create_connection(("127.0.0.1",2000),timeout=5); import time; time.sleep(1)
s.sendall(b"\r\n")
for c in (b"display interface brief\r\n", b"display vlan\r\n"):
    s.sendall(c); time.sleep(2)
    print(s.recv(65535).decode("gbk","replace"))
s.close()
PY'
```
（IAC 协商字节剥离的完整版抄 `D:\20zy\eNSP安装包\ensp_telnet.py`；2000=Jieru-S3700，
2001=Hexin-S5700，按 topo com_port。）GUI 备选：右键设备 → 打开CLI → 剪贴板
set_clip+ctrl+v（控制台认 ctrl+v，同 PT 的 Paste 按钮坑不适用）。

### R4 PC 连通性测试（GUI，PC 无 telnet）——2026-11-04 三 PC 全通实测配方

## 配方

### R7 抓包观察（替代 PT 模拟面板，N14）

1. 右键目标 PC → 数据抓包 ▶ → 子菜单点接口（Ethernet 0/0/1）→ Wireshark 自动起
   （标题 "Capturing from Standard input"，EnumWindows 按 "Capturing from" 找，dumpcap 在抓）。
2. 过滤条 = (L+440, T+106)，set_clip("arp || icmp") + ^v + enter。
3. 清初始态：两台交换机 `sys`→`undo mac-address all`；PC0 控制台 `arp -d`。
4. PC0 控制台 ping 目标 → 等 15s → SetForegroundWindow + 全窗 crop 截图。
5. 收尾 `taskkill /F /IM Wireshark.exe /IM dumpcap.exe`（WM_CLOSE 会弹保存框，别用）。
每轮一个触发；多轮换链路时先杀 Wireshark 再开下一路。

### R8 设备改名（画布标签）

GUI 无法改设备名（设置窗的"主机名"是主机名，不改标签）。正路：eNSP Ctrl+S 保存 →
杀三进程 → 直接改 topo XML 的 `name="..."`（两遍占位法防重名）→ R1 文件关联重开 →
重新最大化 + 启动设备 + 重发路由器配置。PC 的 IP 配置存于 topo 不丢。

### R9 初始态三件套（对应实验三任务 2）

交换机：`sys`→`undo mac-address all`（user view 无此命令）→ `display mac-address` 验空；
PC：`arp -d` → `arp -a` 验空；Router：`ping <PC4 IP>` 预热 → `reset arp dynamic`（清全部动态，
含多余表项）→ 再 `ping` 一次 PC4 → `display arp` 只剩 PC4。
VRP `save` 在 telnet 会话里 (y/n) 秒超时自动取消，配置持久化别指望它，重开后重发配置即可。

### R10 换学号 IP 全量重拍（2026-11-04 实测，~35 分钟）

前提：per-PC 配置脚本、抓包脚本已存档。XXX 前导 0 去掉（051→51）。
1. 路由器：telnet `sys`→两接口 `ip address 210.<XXX>.x.1 255.255.255.0`（覆盖原主 IP）→ display ip interface brief 验证。
2. 5 台 PC：per-PC 脚本 sed 旧网段→新网段，逐台 step（含 PC2 需先 rclick+shot 核对菜单，y=640 向下开）。
3. 重拍顺序：**先**连通性 ping（脏态，首轮丢包正常）→ 清两交换机 + PC0 arp -d + Router `reset arp dynamic`→`ping PC4` 预热（⚠️ 预热会重填右侧交换机 MAC 表，**交换机清表要放在预热之后再补一次**）→ 初始态 GUI 证据（交换机/路由器控制台 + PC0 arp）→ 四路抓包（每轮自带清态）。
4. 证据截图统一走"关旧窗→开新窗→diff hwnd 确认新窗"（N18），命令尽量少敲防 crop 截尾。
5. 报告：重跑生成脚本（内嵌图不随源文件更新，N20）+ 后处理（keepNext/抬头/帧号）+ 重渲染目检。
