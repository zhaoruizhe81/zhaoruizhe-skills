## 可复用配方（全部实测）

### 1. 插入列（可靠配方，3/3 一次成功）
```
clip <字段名>                      # 先设剪贴板
# 网格里右键目标列标题 (x,287)，点"插入列"菜单项 (x+71,460)
menu x 287 x+71 460 shot名
# 下拉获得焦点后直接粘贴+回车：
script: pyautogui.hotkey("ctrl","v"); sleep; press enter; shot 验证
```
坑：菜单项坐标 = 光标x+71, y+173；粘贴必须在本轮 script 内完成（菜单跨轮失效）。

### 2. 网格单元格输入（数字/日期）
**必须剪贴板**：数字键被 IME 拦截，`type("13000")` 无痕失败。流程：
`clip 值` → click 单元格(先 shot 核实行号!) → script: ^v → enter → shot 验证。
行高随名称换行变化（2 行名 ≈54px，1 行名 ≈27px），y 坐标必须现拍现算。

### 3. 筛选器（如"使用资源"筛选某资源）
```
click(695,117) → press f4          # 鼠标点不开下拉，必须 F4
click 菜单项                        # 里程碑=(705,280) 使用资源=(720,351) 清除筛选器=(742,483)
# 使用资源对话框：资源组合框 (935,525)，F4 出列表或直接 clip 资源名+^v，确定(1072,507)
```

### 4. 表格切换（项/成本/工时…）
菜单跨轮失效 → **单脚本一气呵成**：`click(572,140) → shot核对 → 点菜单项`；或键盘法：
`click(572,140) → press down ×N → enter`（从"成本"向下 5 次到"项"）。

### 5. 翻页
滚轮无效。`click 任意任务单元格 → press pgdn`。

### 6. 实验常用序列
- 设基线：项目tab → (583,135) → (650,176) → 对话框确定(950,708)
- 状态日期：`clip 2026/4/30` → (760,92) → ^v → enter
- 更新项目：(715,120) → 对话框确定(1037,604)
- 统计信息：(246,110) → 对话框内"统计信息"按钮(782,751)；关闭(1190,655)
- 任务信息：dclick 任务行 → 高级tab(787,320)/资源tab(743,320)
- 另存为：文件(38,63)→另存为(64,335)→文档(566,227)→文件名(760,396)→保存(811,502)

### 7. 大文件回传 Mac（SFTP 间歇失败时的可靠替代）
PC 端驱动脚本 `shutil.copy` 成 ASCII 名（如 xw2.mpp）→ Mac `scp windowpc:"C:/Users/master/ptauto/xw2.mpp"`。
脚本传输本身失败时用 base64 兜底：
`B64=$(base64 -i local.py|tr -d '\n'); ssh windowpc "powershell -c \"[IO.File]::WriteAllBytes('C:/Users/master/ptauto/scripts/x.py',[Convert]::FromBase64String('$B64'))\""`
