# Navicat Premium Lite — 校准坐标与操作配方

基准环境:windowpc(DESKTOP-KEV6S8M)、1920x1080、窗口**最大化**、
Navicat Premium Lite 17.3.11 简体中文。换分辨率/语言/版本 → 先 `navlib.probe()` 重校。
驱动:windowpc 上走 AUTO/MysqlLab 桥(mysql_lab.py,一次性命令+script 通道),
不用标准 pt.py 栈;远程直驱封装与坑见 remote/远程坑.md §9。
表设计器(建表/主键/外键/CHECK/索引)全流程配方见下方配方 7,私有坑见 踩坑.md §8-§11。

## 配方

### 0. 会话开始:清弹窗 + 前置窗口
```
nags_click([(958,548),(1324,311),(798,616)])   # 无弹窗时点空白, 无副作用
raise_topmost("Navicat"); maximize()
```

### 1. 打开连接(登录 MySQL)
双击 CONN_ROW → 等树展开。成功标志:连接图标变绿、状态栏出现"N 数据库"、
右侧面板显示 主机 localhost / 端口 3306 / 用户名 root / 服务器版本。

### 2. 登录 Navicat ID(免费版必须登录; 会话过期会引导到此流程)
点 LOGIN_CLOSE 关掉可能开着的旧框 → 点 NAG_OK → paste_at 邮箱 → paste_at 密码 →
点 LOGIN_BTN → 等 10s → 点 LOGIN_DONE。
真实凭证:zhaoruizhe81@gmail.com 有效;2406875129@qq.com 无效(已验证)。

### 3. 新建数据库(实验 5①)
右键 CONN_ROW → 上下文菜单点"新建数据库..."(原子菜单 (135,319))→
名称框 paste 数据库名 → 确定 → 树里出现新库、状态栏计数 +1。

### 4. 查看数据库状态(实验 6①)
点选数据库行:左树高亮 + 右侧属性面板(字符集 utf8mb4 / 排序规则 / 所属连接)。
连接的"打开/关闭"以图标颜色为准(绿=已连接)。

### 5. 删除数据库(实验 7①)
右键目标库行 → 上下文菜单点"删除数据库"(原子菜单)→ 勾"我了解此操作具永久性"
→ 删除按钮激活 → 点删除 → 状态栏计数 -1、树中该行消失。

### 6. 命令列界面(备用)
右键连接 → "命令列界面..."可打开 Navicat 内嵌 mysql 终端;本机实验优先用
系统 cmd(更符合实验报告要求),此处仅作备用入口。

### 7. 表设计器全流程(实验一实战,1920x1080,行高约22px)
前提:对象 tab(332,128)下点"新建表"(460,159)。设计器打开后:
- 字段页签行坐标:行1 y=233,行2 y=256,行3 y=278,行4 y=300,行5 y=322(保存重载后行1 y=239,行高22)。
- **列类型直接粘完整定义**(名称格 440,类型格 610):点击格 → ^a → set_clip("CHAR(9)") → ^v → ENTER。
  不碰长度格(707)/小数点格(762),避开校验坑。
- 新行:点"添加字段"(400,158)前先 ESC 清编辑态;填完一行立即点其他已有行提交;禁用 ESC 撤新行。
- 主键:点行头(315,y)选中行 → 主键按钮(650,158);复合主键逐行追加。
- **每加一字段 Ctrl+S**(首次保存弹"另存为"框:表名框(958,517)→保存(919,556))。
- 索引/外键/检查页签:空行各格直接点击→^a→粘贴→ENTER;外键格坐标(行1 y=240):
  名称360/字段470/被引用模式600/被引用表725/被引用字段850。
- 验证:SQL 预览 tab(672,185)看 DDL;PC 侧 mysql.exe 直查 SHOW CREATE TABLE 双通道确认。
- course 表右键"设计表"菜单项:右键表行(350,210)→菜单项(430,271)。
