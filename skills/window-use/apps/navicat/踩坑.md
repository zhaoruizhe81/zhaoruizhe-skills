# Navicat Premium Lite 私有坑(公共坑见根目录 踩坑清单.md)

SKILL/速查表引用本文件条目时写作 navicat #N（标题即 N）。

## 1. 免费版登录墙:不登录不给用
- Navicat Premium Lite 17.3.x 强制 Navicat ID 登录;未登录/会话过期时弹全屏"注册/登录"框,
  挡住一切菜单操作。
- **解法**:向用户要账号(本次 zhaoruizhe81@gmail.com 有效,2406875129@qq.com 无效),
  按 坐标与配方.md 配方 2 登录一次。GUI 填表用 `paste_at`(点框→^a→^v),邮箱里的 @ 走剪贴板。

## 2. "订阅会话已过期"周期弹窗(登录后仍会弹)
- 登录后每 60~90 秒弹一次小提示框,专挑操作的间隙出现:关上下文菜单、抢焦点、
  让"右键完还没点菜单项"的跨命令流程报废。
- **解法**:① 每条流程开头 `nags_click(NAGS)` 清一次;② 右键→点菜单项必须原子
  (`atomic_menu`,公共坑 #18);③ 长流程用重试循环,被打断靠下一轮自愈(公共坑 #19)。

## 3. 更新弹窗
- 偶发"有新的版本可用"(17.3.12),点"跳过此版本"(UPDATE_SKIP)。别点下载——
  版本变了坐标全部要重校。

## 4. 上下文菜单项坐标 = 右键锚点 + 固定偏移(菜单不动,锚点动)
- 菜单锚定在右键位置弹出:右键连接项 (70,155) → "新建数据库..." 在 (135,319);
  右键数据库行 (90,214) → "删除数据库" 在 (140,303)。
- **数据库行的 y 不是常数**:树按字母序排列,建/删都会让行位移(实测 gradem 删除前后
  同一坐标从 gradem 行变成 Net.Tcp 行)。解法:动手前截图数行,`y = 174 + 20 × 序号`。

## 5. 状态栏计数是最可靠的验证通道
- 左下角"N 数据库"随建/删精确 ±1(本次 9→10→9),比看树更不容易看走眼;
  配合 MySQL 旁路 `SHOW DATABASES`(SSH 直跑 bin/mysql.exe)双通道验证。

## 6. Qt 界面的 UIA 支持一般
- 主窗口/对话框能被 win32+uia 找到(标题含 "Navicat"),但树项/菜单项的 UIA 枚举
  没有验证过——本次全部用校准坐标 + 截图闭环完成。想升级成 UIA 定位先 probe 验证,
  别直接信。

## 7. Windows MySQL 库名不区分大小写
- `CREATE DATABASE MyDB` 建出来的是 mydb;残留同名旧库会让建库报 1007。
  动手前 SSH 旁路 `SHOW DATABASES` 摸底(本次清理过遗留 mydb)。

## 8. 表设计器网格:点空白不加行 + ESC 撤销未提交新行(2026-10-28 实验一实付)
- 新建表设计器默认只有 1 行;点击网格空白**不会**新增行,必须点工具栏"添加字段"(400,158)。
- "添加字段"前若有单元格处于编辑态,点击会被编辑态吞掉(无效且无提示)。先 ESC 清编辑态再点。
- **新行未提交时按 ESC = 撤销整行**(数据直接消失,无确认)。已提交行上的 ESC 只是取消编辑。
  新行填完后用点击其他已有行的格子来提交,绝不要 ESC。本坑实付两次"Sname 行消失"。
- 网格行列中心(1920x1080,最大化,行高约 22px,行1 y=233):名称 x=440、类型 x=610、
  长度 x=707、小数点 x=762、不是null x=818、虚拟 x=875、键 x=925、行头选中 x=315。
- **类型格直接粘贴"CHAR(9)"完整定义可自动解析**,无需碰长度格(绕开最易错的列);
  但粘贴前必须 ^a 全选,否则默认值"int"残留成"intCHAR(9)"。
- 长度格粘贴非法值(如文本)会弹模态错误框并卡住编辑态,吞掉后续一切点击;
  粘贴进格子的值可能是最后一条,ESC 后才暴露。解法:ESC 退编辑态 → 重填。

## 9. Premium Lite 17.3.11 "添加字段"内部 bug 崩溃(实付 3 次崩溃)
- 多次"添加字段/插入字段"混用后触发 Unknown Internal Error
  (insert Index is larger than COLList::size / Access violation),之后每次操作都崩。
- 对策:**尽早保存命名**(第一次保存弹表名框,填名确定),之后**每加一个字段立即 Ctrl+S**;
  即使崩溃,已保存进度不丢。崩溃报告对话框可关,主程序可能仍存活(实测关掉后还能保存)。
- 字段 tab 的"主键"按钮是切换式:点主键前必须确保目标行处于**行选中**(点行头 x=315),
  格编辑态下点按钮无效。复合主键 = 依次对每行点主键按钮(键列显示 1、2)。

## 10. 工具栏按钮语义随当前 tab 变化
- 对象视图下 (460,159)="新建表";表设计器打开时同行位置是"添加字段"附近
  (设计器工具栏:保存336/添加字段400/插入字段485/删除字段565/主键650,y=158)。
  新建表前必须先回到对象 tab(点"对象"标签 332,128)再点工具栏,否则误加字段。
- 设计器各 tab x 坐标(y=185):字段332/索引370/外键418/检查467/触发器520/选项563/注释612/SQL预览672。

## 11. 索引/外键/检查 tab 的填法(2026-10-28 实测)
- 索引 tab 的"索引类型"下拉**没有 PRIMARY**(只有 FULLTEXT/NORMAL/SPATIAL/UNIQUE);
  主键必须回字段 tab 用"主键"按钮设置。索引 tab 可直接看/编辑二级索引,名称格可直接键入。
- 外键 tab:名称、字段、被引用的表、被引用的字段四个格**都可以直接键入文本**
  (先点格获得编辑态 → ^a ^v → ENTER);"..."选择器确定后经常不回填,别依赖。
  被引用的模式会自动填当前库。填完被引用的表之前,被引用的字段可能拒绝生效。
- 检查 tab(CHECK 约束):名称格 + 检查表达式格直接键入即可(如 Grade BETWEEN 0 AND 100),
  Navicat 自动加反引号规范化;MySQL 8.0.16+ 真实执行 CHECK。
- 表设计器内嵌"SQL 预览"tab(672,185)是最佳验证点:填完字段/约束后切过去看生成的 DDL。
