## do 文件模板（全 VHDL！Starter 版禁混编）
```
onerror {quit -f}
vlib work
vcom -work work a.vhd
vcom -work work b.vhd
vcom -work work xxx_tb.vhd
vsim -novopt -c -t 1ns work.xxx_tb
add wave -radix unsigned sim:/xxx_tb/<sig>
run 350 ns
wave zoom full   ← console 版会忽略，GUI 版有效
```

## 单工程证据三件套（编辑器截图 / RTL / 波形）

### 0. 启动纪律（坑 公36/37/38）
- 远程命令第一句永远 `export MSYS_NO_PATHCONV=1;`
- 启动 bat 用 heredoc 写、`sed` 补 CRLF、程序行必须 `start ""`；每次 `schtasks /end /tn X` 后再 `/run`
- 程序起没起以 tasklist + 截图为准，别信 schtasks 回显

## Keil C51 µVision 辅助配方（任务4：8051 软核 + Keil 程序，2026-11-03 实战）
- CLI 编译：`/c/Keil_v5/UV4/UV4.exe -b <proj>.uvproj -j0 -o build.log`（exit 1=有警告仍成功，2=错误；log 看 "0 Error(s)" 与 "creating hex file"）
- GUI 窗口标题 `xxx.uvproj - µVision`，raise 子串用 **"Vision"**（不是 uvVision/Keil，且 raise_topmost 不返回值、找不到会抛错——不要 `raise(a) or raise(b)` 链式兜底）
- 打开项目必弹 "C:\KEIL\C51\INC\REG52.H contains an incorrect path" 警告（项目存了作者机器旧包含路径）→ 点确定 (318,136) 即可，CLI/编译不受影响
- F7=Build；Build Output 自动出现在底部（"0 Error(s)" + hex 生成即证据），窗口最大化 + 点编辑区 (900,500) 拿焦点后按
- 全编译（Quartus 侧 51 系统）：工具栏 ▶ 实测 (631,62)；编完弹 "Full Compilation was successful (N warnings)" 模态框，OK 在右下 (~1885,1058)，点掉后 Compilation Report 自动打开（Flow Summary 顶层可见）
