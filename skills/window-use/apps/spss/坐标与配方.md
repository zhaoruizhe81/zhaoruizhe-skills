校准基准：IBM SPSS Statistics 27 中文版 @1920×1080、100% DPI、窗口最大化。
2026-10-22 统计作业 + 2026-10-25 中心极限定理验证/十任务实训 + 2026-10-26 两独立样本t检验（习题6-4）实战沉淀。

## 三、可靠配方

### 配方 A：跑一套多步统计（推荐唯一姿势）

1. **合并语法**：所有步骤写进**一个** .sps（UTF-8 带 BOM + CRLF），开头 `SET SEED=...` 固定随机种子。
   stats.exe 每次 Popen 都是全新实例（SP#7），分文件分轮跑必丢数据集。
2. `spsslib.launch_with_sps(path)` → `spsslib.clear_startup_popups()`（**先清弹窗**）→
   `spsslib.run_syntax(文件名子串, wait_s=..., shotname=...)`。
3. 输出验证：pull 截图看有无红色错误文本（语法错进"日志"对象）。

统计链路常用语法（CLT 类作业直接复用，2026-10-25 全链路实跑通过）：
```sps
* 生成两总体并出统计量+直方图（传统 GRAPH，GPL 不可用 SP#2）.
MEANS TABLES=x BY dist /CELLS=COUNT MEAN STDDEV VARIANCE MIN MAX.
SPLIT FILE LAYERED BY dist.
GRAPH /HISTOGRAM(NORMAL)=x /TITLE='...'.
SPLIT FILE OFF.
* 有放回抽样：随机索引 + MATCH FILES 取回观测 + AGGREGATE 分组.
MATCH FILES /FILE=* /TABLE=pop /BY dist id.
AGGREGATE /OUTFILE=* MODE=ADDVARIABLES /BREAK=dist g /grp_n=N /grp_mean=MEAN(x) /grp_sd=SD(x).
SELECT IF (j=1).
* 正态性检验+点估计一条命令全出（描述统计/K-S/S-W/直方图/Q-Q）.
EXAMINE VARIABLES=grp_mean BY dist /PLOT HISTOGRAM NPPLOT /STATISTICS DESCRIPTIVES /CINTERVAL 95 /NOTOTAL.
* 置信区间与覆盖率（t 临界值用 IDF.T）.
COMPUTE ci_lo=grp_mean-IDF.T(0.975,34)*grp_sd/SQRT(grp_n).
COMPUTE cover=(ci_lo LE pop_mean AND pop_mean LE ci_hi).
CROSSTABS /TABLES=cover BY dist /CELLS=COUNT.
```

### 配方 B：结果截图（多对象）

弃大纲定位（点击自动滚动+UIA 枚举 0 个，SP#9），走**内容窗格翻页**：
`spsslib.page_viewer(pages=N, direction="pgdn", shot_prefix="pg")`，每屏 ≈980px，
拉回 Mac 后按内容裁剪对象。要点：
- 每次翻页前 `click(1400,500)` 拿焦点；`^home` 复位不总生效，翻页序列要么从当前真实位置起算，要么先全屏 shot 核对。
- 长表（如 30 组×多列）会跨屏，相邻两屏在 Mac 上各裁一半或拼接。
- 单对象精确截图才用大纲点击（SP#4/SP#5），点完立即 shot，不跨多对象复用坐标。

### 配方 C：数据编辑器截图

`spsslib.shoot_data_view("[smp]", tab="data", shotname="dv")`——先最大化再点标签；
`^home` 回左上角不总生效，若截到中部，直接重跑一次本函数（第二次往往已聚焦到位）或接受中部视图。


### 配方 D：批量任务（多章/多题）新鲜启动循环（2026-10-25 十任务实训实战沉淀）

每个任务一份**自包含 .sps**（数据 BEGIN DATA 内嵌 + DATASET NAME + 全部分析），循环：
`taskkill /F stats.exe → 清 autoRecovery 目录 → Popen launch → 清弹窗 → 等窗口使能 → ^a^r → 等待 → 翻页截图 + 数据视图截图`。
- 强杀后**必清** `%AppData%\Roaming\IBM\SPSS\Statistics\27\autoRecovery\*`（SP#8 两连弹的主要诱因，清后多次启动零弹窗）。
- 等待循环里**持续轮询清弹窗**（弹窗会在启动后 30~60s 才冒出来，固定清一次必漏），每轮 `popup_titles → 清 → find_window(timeout=4)` 直到使能。
- 清弹窗姿势：先 Qt 式点击（moveTo→mouseDown→mouseUp，公#11b），失败再 esc→alt+F4 兜底（SP#11）。
- 好处：数据集名零冲突、查看器从第 1 页起翻页截图、单任务失败只重跑该章。
- 翻页截图**必须在杀实例前拍完**（血泪：图表截图没拍就 kill，整章重跑）。

### 配方 E：两独立样本 t 检验（"两组有无显著差异"类作业一把梭，2026-10-26 全链路实跑通过）

一条 T-TEST 同时产出：组统计量、Levene 方差齐性检验、假定/不假定等方差两行 t 检验、差值95%CI、
效应大小（SPSS 27 默认带 Cohen d/Hedges/Glass）——教材式"假设检验五步"要的数字全在这两张表里：

```sps
DATA LIST FREE /method score.
BEGIN DATA
1 56
1 49
2 59
2 52
END DATA.
DATASET NAME train64.
VARIABLE LABELS method '培训方法' score '测试分数'.
VALUE LABELS method 1 '方法1' 2 '方法2'.
EXECUTE.
T-TEST GROUPS=method(1 2)
  /VARIABLES=score
  /CRITERIA=CI(.95).
```

要点：
- 数据用"组别 分数"数值对逐行内嵌，最稳（免 SP#10 字节宽度坑）。
- T-TEST 这类小输出**一屏装得下，不用配方 B 翻页**：run_syntax 的整窗 shot 直接当证据，
  Mac 端按内容裁表即可（6-4 全部 5 张证据图都这么出，翻页一轮没跑）。
- 配对设计换 `T-TEST PAIRS=前 WITH 后 (PAIRED)`；单样本换 `/TESTVAL=v`。
- 本地核对基准：scipy `ttest_ind(equal_var=True/False)` + `levene(center='mean')`
  （SPSS 的 Levene 基于均值；scipy 默认 center='median' 会对不上，必传）。

### 中文数据 DATA LIST 规则（SP#10）
- 字符串宽度按**字节**算：UTF-8 中文每字 3 字节。宽度 = 最长值字数×3 + 余量（类别 A16、地区 A12、长标签 A30）。
- 跑完第一件事看 FREQUENCIES 的"个案数/缺失"——超宽行**整行静默变系统缺失**，不报语法错。
- 生成语法后自检：每个数据行 token 数 == 变量数（注意 `(5F8.0)` 重复因子算 5 个）。

### 统计语法坑（SP#14）
- `RECODE x (...) INTO 新变量` 偶发静默不生成（中文变量名，原因未查明）；FORMATS/VALUE LABELS 报"变量未定义"即中招。直接换等价写法：`COMPUTE 新=1. IF (x GT 切点) 新=2. EXE.`
- CLUSTER 的 `/PLOT` 只认 `DENDROGRAM VICICLE HICICLE NONE`，裸 `ICICLE` 报错且整条命令停止（SAVE 也丢弃）；Ward 法配 `/MEASURE=SEUCLID`（平方欧氏距离，EUCLID 会有警告且分组结果差、不可解释）。
- 加权列联表：数值码 + `VALUE LABELS` + `WEIGHT BY 数值列` + `CROSSTABS /CELLS=COUNT`，单元格计数即数值合计（CROSSTABS 不吃字符串变量）。
