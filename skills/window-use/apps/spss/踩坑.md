# SPSS Statistics 27 (Windows 中文版) 踩坑 — 2026-10-22 统计作业实战（Mac 遥控 windowpc）

全程实付验证。SPSS 27 安装路径 `C:\Program Files\IBM\SPSS\Statistics\27\stats.exe`，中文界面。

## SP#1 可靠驱动方式：.sps 文件直开 + ^a^r，不走菜单点分析
- **做法**：把全部语法写进 .sps（UTF-8 **带 BOM** + CRLF），`Popen([stats.exe, r"C:\...\x.sps"])`
  直接在语法编辑器打开 → `w.type_keys("^a^r")` 全选运行。
- 中文变量名/中文注释全程无乱码（BOM 是关键，无 BOM 会按 GBK 读导致语法错）。
- 等窗口 `is_enabled()` 为真再发键（SPSS 冷启动 40~60s，窗口先出现后使能，
  过早 type_keys 抛 ElementNotEnabled —— 2026-10-22 实付一次）。

## SP#2 GPL 图形块不可用，用传统 GRAPH 语法
- `GGRAPH/BEGIN GPL` 无论中文还是英文变量名都报 "GPL 错误: SOURCE: gdX"（两次实付，
  英文变量名+RENAME+VARSTOCASES 也没救回来，根因未查明，别再试）。
- **可靠替代**：传统 `GRAPH /LINE(MULTIPLE)= MEAN(v1) MEAN(v2) ... BY 分类变量.`
  （旧对话框"多线折线图-各变量的摘要"生成的语法）。注意裸变量列表（不带 MEAN()）
  会画出错误图形（实付：图例变成 2016年/1,2,3,4）。

## SP#3 菜单/导出对话框：纯坐标是唯一稳路
- 查看器窗口 `menu()`/`menu_select()` 返回 None 不可用；Alt+加速键可行但**开菜单与
  点菜单项必须同一驱动轮次**（公#18 再现），且中文 IME 吃单字母键。
- **最稳：Alt+F 后 `{DOWN n}{ENTER}` 方向键导航**（文件菜单第 9 项=导出(T)，n=8）。
- "导出输出"对话框是自绘控件：win32 后台 `descendants()` 返回 **0 个控件**，UIA
  按钮匹配全失效 → 全坐标：类型下拉(757,323) → PDF 选项(664,366) → 文件名用
  `pt.py send paste 955 555 <路径>` → 确定(839,829)。（1920×1080）

## SP#4 PDF 导出丢中文 —— 别用
- 导出 PDF 成功但**表格标签、图表内中文全部空白**（CJK 字体未嵌入）。
- **正解：输出查看器逐对象截图**——大纲点击叶子条目选中对象 → 全屏 shot →
  Mac 本地按坐标裁剪。文件即"SPSS 里直接的截图"，像素级中文无误。

## SP#5 大纲点击的滚动行为
- 点击大纲条目：对象**已完全可见时内容面板不滚动**，只有不可见/部分可见才滚。
- 滚动手段：内容面板空白处单击（别点在图表上）→ `press pgdn/pgup` 翻页；
  微调用 `send drag 1907 <y> 1907 <y+70>` 拖滚动条（60px 拖动约滚 400px 文档）。

## SP#6 输出文档会分裂 + 关闭/恢复对话框坐标
- 每轮 ^a^r 输出进"指定输出文档"，多查看器窗口并存时输出进哪个不可控；
  干净重跑的套路：关查看器（保存提示点"否"）→ 重跑全部语法文件。
- 关查看器/强杀恢复的模态对话框 UIA 按钮抓不到，坐标：保存提示"否(N)"(960,551)、
  错误报告"取消"(1221,808)、会话管理"取消"(958,733)、打开数据"取消"(1210,603)。
- `taskkill /F /IM stats.exe`（远端 `MSYS_NO_PATHCONV=1` 前缀）后重启必弹错误报告
  +会话管理两连弹，逐个坐标点掉即可，不影响继续工作。

## SP#7 Popen 第二次 stats.exe = 全新实例，数据集不共享（2026-10-25 实付）
- **症状**：第一轮 .sps 跑完建好数据集 pop，第二轮 Popen 新 .sps 后报"错误 63 文件不存在 pop"、
  变量 dist 未定义；`tasklist` 出现**两个** stats.exe。
- **原因**：从桥再 Popen 一次 stats.exe 会起独立新实例（不是在同实例开文档），里面没有任何数据集。
- **解法**：多步语法**合并成一个 .sps** 在同一实例一次 `^a^r` 跑完（SET SEED 固定种子保证可复现）；
  若必须分轮，走窗口菜单"文件→打开→语法"而不是再 Popen。

## SP#8 强杀后恢复弹窗是自绘窗口，且在语法窗口可使能**之前**弹出（2026-10-25 实付）
- **症状**：taskkill 后重启，"IBM SPSS Statistics 错误报告服务"+"会话管理"弹窗挡路；
  按 `#32770` 类名过滤枚举**不到**它们（自绘窗口类不是 #32770），等待语法窗口
  `is_enabled()` 的循环 240s 超时——清理动作排在了等窗口之后：**必须先清弹窗再等窗口使能**，顺序反了必超时。
- **解法**：用 GetWindowText 按标题含"错误报告/会话管理"检测（win32 后端枚举顶层窗口即可），
  检测到就按 SP#6 坐标点取消（1221,808 → 958,733），清完再等 `spss5_all` 窗口使能。
  取消会话管理会把崩溃会话的语法窗口一并丢弃——别指望它还在。

## SP#9 查看器大纲点击会自动滚动，坐标截图改走内容窗格翻页（2026-10-25 实付）
- **症状**：按校准坐标逐叶点击大纲截图，点了几叶后坐标全体漂移（点条目时 SPSS 自动滚大纲使
  选中项居中）；`press home` 焦点不在树上时**不会**重置大纲；UIA `descendants(TreeItem)`
  对查看器返回 **0 个**（大纲树不暴露 UIA，与 SP#3 一致）。
- **解法（可靠）**：放弃大纲定位，**内容窗格直接翻页**：点内容区空白处拿焦点 → `pgdn`/`pgup`
  逐屏截图（每屏≈980px），Mac 端按内容裁剪对象；翻页前同样要点一下内容区，`^home` 复位
  不总生效。12 张对象图一轮翻页脚本（只读操作可一批 4-5 屏）全部拿到。
- 教训：同页版 SP#4/SP#5 的"大纲点击法"适合单对象精确定位，**多对象批量截图走翻页更稳**。

## SP#10 DATA LIST 字符串宽度按字节算，中文超宽整行静默变缺失（2026-10-25 实付）
- **症状**：FREQUENCIES 显示"缺失=10"，整整一个类别（拉丁美洲）10 国数据消失，无语法报错。
- **原因**：`类别 (A10)` 是 10 **字节**，UTF-8 中文每字 3 字节，"拉丁美洲"=12 字节超宽 → 该行整行解析失败成系统缺失。A10 装得下 3 字类的"亚洲"，装不下 4 字类——最具迷惑性。
- **解法**：中文串宽度按"最长值字数×3+余量"声明（类别 A16、地区 A12、长标签 A30）；跑完先查"个案数/缺失"再继续。

## SP#11 错误报告弹窗有两代布局，且吞普通 click（2026-10-25 实付）
- **症状**：按校准坐标 (1221,808) 点"取消"连点 4 次弹窗纹丝不动。
- **原因**：① 弹窗有两代布局，新版多一个"共同信息(M)"按钮，取消键实测在 **(1257,809)**，校准坐标落在两按钮之间的空隙；② 该自绘弹窗吞 `pyautogui.click` 单击。
- **解法**：`moveTo→mouseDown→sleep(0.15)→mouseUp`（Qt 式点击，公#11b 同源）+ 实测坐标。会话管理弹窗的老坐标 (958,733) 仍有效。

## SP#12 恢复弹窗是多层队列，每层"否"的位置都不同（2026-10-25 实付）
- 强杀后依次弹出：错误报告(1257,809) → 会话管理(958,733) → **语法保存提示(961,556)** → **数据集保存提示(958,574)** → **"退出SPSS"确认(967,604)**。老校准只覆盖查看器保存提示 (960,551)。
- 解法：逐层截图→crop 放大实测按钮→点掉→再截图，循环到无弹窗；"退出SPSS"确认点"是"可直接干净退出整个实例（配合每章自包含 .sps 新鲜启动最稳）。

## SP#13 语法窗口丢了别再 Popen，用"文件→新建→语法+剪贴板"在同一实例重建（2026-10-25 实付）
- 会话管理点取消会丢弃崩溃会话的语法窗口（SP#8 已记）。同一实例里重建：数据编辑器置前 → `alt+f → down → right → down → enter`（纯方向键防 IME，文件→新建→语法）→ 新语法窗口 `set_clip(语法全文)` + `^a ^v` 替换 → `^a ^r`。比 Popen 新实例（SP#7）和菜单打开文件都稳。
- 补跑/修数据时同理：片段语法贴进**新建**语法窗口 `^a^r`，只跑片段，不重跑全文件（避免 DATASET NAME 冲突）。

## SP#14 RECODE INTO 中文目标变量偶发静默不生成（2026-10-25 实付，原因未查明）
- **症状**：`RECODE 出口 (LOWEST THRU 2764.17=1)... INTO 出口分组.` 语法窗口内容完好、与同文件成功的人口/人均GDP 两条 RECODE 完全同构，但变量未创建；后续 FORMATS 报 4820"变量尚未定义"。
- **解法**：别恋战，直接换等价写法——`COMPUTE 分组=1. IF (x GT 切点) 分组=2. IF (...) 分组=3. EXE.` 一次通过。判断标准：FORMATS/VALUE LABELS 报"变量未定义"= 上游 RECODE 没生效，换 COMPUTE+IF。

## SP#17 CLUSTER 的 /PLOT 裸 ICICLE 不被认，整条命令静默停止（2026-10-25 实付）
- **症状**：`/PLOT=DENDROGRAM ICICLE` 报"PLOT 指定项无效…NONE、VICICLE、HICICLE、DENDROGRAM"，随后**树状图冰柱图全没有、SAVE 的群集变量也没建**，下游 FREQUENCIES/MEANS 全部连环报"变量未定义"。
- **解法**：裸 `ICICLE` 改 `VICICLE`（纵向冰柱图，教材样式）；Ward 法配 `/MEASURE=SEUCLID`（EUCLID 会有"应使用平方欧氏距离"警告且分组不可解释：北京河北山西被聚同群）。

## SP#15 tasklist 过滤参数在 Git Bash ssh exec 里静默失败（远§2 变体）
- `cmd.exe /c "tasklist /FI \"...\""` 嵌套引号被吞，只回显 cmd banner，**看起来执行了其实什么都没查**——会误判"进程不存在"。
- 解法：`tasklist | grep -i stats`，别用 /FI。

## SP#16 "打开数据"对话框有变体，取消键不在校准位（2026-10-25 实付）
- 菜单/工具栏误触会弹出"从网格位置打开数据文件"变体，取消键实测 **(1023,706)**，与校准的 (1210,603) 不同。同上：crop 实测再点。

## SP#18 启动恢复弹窗会晚于固定 sleep 出现；两按钮版"取消"坐标不同（2026-10-26 实付）
- 症状①：launch 后固定 sleep 12s 再 clear_startup_popups 返回空，几秒后"错误报告服务"弹窗才冒出来，
  阻塞语法窗口使能 → run_syntax 等 240s 超时 FAIL（^a^r 从未发出，无半执行态）。
  **"语法窗口 not enabled 超时"十有八九是弹窗挡道——先 shot 取证再动手。**
- 解法①：run_syntax 前用 popup_titles() 轮询清弹窗（循环到无弹窗），别依赖任何固定 sleep。
- 症状②：错误报告弹窗不止两代，还有宽度差：**两按钮版**（单个信息(M)+发送(S)+取消，窗口 620×600）
  取消中心实测 **(1215,810)**；SP#11 的 (1257,809) 是三按钮更宽的布局。照抄旧坐标会点到按钮右侧空白。
- 解法②：点前先 `crop` 弹窗按钮区实测位置（一轮 15s），qclick(moveTo/mouseDown/sleep/mouseUp) 一次通过。
- 症状③：错误报告弹窗点"取消"后，以 .sps 启动的语法窗口**并没有被丢弃**，只是被自动弹出的
  空白数据编辑器挡住——find_window(文件名子串) 照常找到并 ^a^r 即可，不必走 SP#13 重建。
