## 配方
1. **跑分格代码（# %% 单元格）**：点击目标单元格内 → Ctrl+Enter 运行当前格。
   【待验证】本次未走到这步；按键经 pyautogui.hotkey("ctrl","enter")。
2. **内核起不来时**：独立起内核（实测✓）
   `Popen([python, "-m", "spyder_kernels.console", "-f", "C:\\...\\k.json"], stdout=文件, stderr=文件)`
   → 20s 内 k.json 出现即就绪 → GUI 里 Consoles → Connect to existing kernel 填路径【待验证】。
3. **控制台截图**：driver `shot` 全屏 + crop 控制台面板区域（窗口最大化时下半屏左 2/3）。
