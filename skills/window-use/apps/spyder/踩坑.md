# Spyder 私有坑（2026-10-20 实验2 Pandas 实战，windowpc 1920x1080）

## 首启弹窗：Spyder tour 挡住一切
- **症状**：首次启动弹出 "Welcome to Spyder!" tour 对话框，挡住中栏。
- **解法**：点 Dismiss（1920x1080 实测坐标 1160,586）；启动后 75s 内必现，截图确认后再动别处。

## 内核自启失败（红框 "An error occurred while starting the kernel"）
- **症状**：Spyder 6.1.7 起不来自带内核，控制台红色报错框只显示 requests 的 RequestsDependencyWarning，
  之后一直 "Connecting to kernel..."；tasklist 能看到 48MB 的 python.exe 内核进程挂着但不握手。
- **排查实况**：版本配对正常（spyder 6.1.7 + spyder_kernels 3.1.6）、import 全通、
  **独立命令行起内核 20s 内就绪**（`python -m spyder_kernels.console -f xx.json`，连接文件出现即成功）。
  根因未查明——红框原文没读（公共坑 #34 的实付案例）。
- **绕过（最可能可行，GUI 步骤待验证）**：独立 Popen 起内核留活 → Spyder 菜单
  Consoles → Connect to existing kernel → 填连接文件路径。
- **教训**：先 crop 红框读原文，再做无头验证。

## Mac 端别想 CUA：Spyder 全输入被拒
- **症状**：macOS computer-use 对 conda 直启的 Spyder（无 bundle id 的 python 进程）键盘/点击/自带截屏全拒；
  Qt a11y 树只读（所有元素 allowed:[]），菜单也按不动。
- **解法**：别在 Mac 上死磕，走 window-use 遥控 Windows PC（本包）。系统级 `screencapture -l <窗口id>` 截图可用，
  但只能看不能点，只够用来"看现场"。

## 配置启动脚本（Mac 无头方案的遗产，可用但脆）
- `~/.spyder-py3/config/spyder.ini`：`startup/use_run_file = True` + `startup/run_file = <py路径>`，
  启动时自动执行并显示 "Output from spyder call 'safe_exec'"——但**只稳定显示最后一次 print**，
  且控制台组件没就绪时输出可能整体丢失（竞态，两次复现一次丢失）。每问一重启才可靠，慢。
- 改配置前必须确认所有 Spyder 进程已退（退出时回写配置会覆盖你的修改，实付一次）。
- 崩溃/kill 后残留 ~/.spyder-py3/autosave/*.py → 下次启动弹 "Recover from autosave" 模态框卡死启动，
  先删掉再启动。
