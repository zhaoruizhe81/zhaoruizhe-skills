前提:窗口最大化(win+up)。全部坐标为绝对像素,同分辨率可直接盲跑;sqllab 无 probe 自检,换分辨率/换机需重新校准本表坐标。

## 配方

### 配方A:新建连接(填对话框)
对话框字段:Name(1063,317) 用户名(1063,451) 密码(1063,479) 保存口令勾选(1239,479) 服务名radio(860,647) 服务名输入(1145,647);按钮:测试(1125,739) 保存(923,739) 连接(1222,739)。
流程:点 "+" → 逐字段 `paste_at`(见 sqllab.fill_connection)→ 测试 → shot 看左下"状态: 成功" → 保存 → 连接 → shot 确认标题栏变 `Oracle SQL Developer: <连接名>`。

### 配方B:工作表执行 SQL 脚本(核心循环)
```
click(700,250) → paste_at(700,250, sql文本) → sleep2 → click(382,122) → sleep(执行秒数) → shot
```
验证:shot 里"脚本输出"区有预期行(已创建/已插入/N行已删除/提交完成)。前置检查:**shot 确认活动标签是工作表**(粘贴进表数据网格会污染数据,见踩坑8)。

### 配方C:数据页签插入一行
双击树中表 → (394,121) 数据页签 → sleep8 → (407,143) 添加行 → **shot 确认新行行号** → 点新行第1列 → set_clip+^v → 点第2列 → set_clip+^v → shot 核对值 → (458,143) 提交 → shot 看消息-日志"提交成功"。
出错恢复:未提交的烂编辑 → (395,143) 取消编辑 → 弹窗点 否 → 重新来。

### 配方D:数据页签删除一行
选中目标行行头 → shot 确认整行高亮 → (437,143) 删除 → (458,143) 提交 → shot 确认行数-1 且日志有 DELETE 语句。

### 配方E:SQL*Plus 控制台
driver 脚本里 `subprocess.Popen('cmd /k title SQLPlusDemo', shell=True)`(驱动在桌面会话,窗口可见)→ raise_topmost → win+up 最大化 → 点窗口内(900,400) → set_clip 逐条粘贴 SQL+回车,每条间隔 sleep。连接串:`sqlplus yggl/yggl123@//localhost:1521/FREEPDB1`。

### 配方F:误关标签/工作表恢复
右键连接节点(如 (54,166)) → 菜单"打开 SQL 工作表(U)"(实测 (140,668),菜单项坐标随屏幕会漂,先 rclick+shot 取证再点)。

### 配方G:向导方式创建视图(题18 类任务)
右键连接树"视图"节点(70,202) → 菜单"新建视图(V)..."(135,217,菜单可跨轮存活,见踩坑13) → "创建视图"对话框:名称框(870,350,默认 VIEW 全选态,直接 paste 覆盖) → SQL 查询区(900,470 点入后 ^a 再 ^v 覆盖模板) → "检查语法"(693,698,结果显示在下方"语法结果"区,成功="SQL中未发现错误") → "确定"(1136,739)。创建后视图即时可用,树节点需展开/刷新才显示。
