# SQL Developer(Oracle)应用包 · 踩坑与配方(2026-10-19 实验1实战)

环境:windowpc 1920x1080,Oracle AI Database 26ai Free(SID=FREE,PDB=FREEPDB1),SQL Developer 24.3.1 解压版在 C:\sqldev\sqldeveloper\sqldeveloper.exe。

## 踩坑

1. **zip 布局与启动 cwd**:exe 在 `sqldeveloper\sqldeveloper.exe`(内层还有同名目录,含 bin\sqldeveloper.conf)。Git Bash `unzip -o` 半途损坏会报 "Unable to open ... bin\sqldeveloper.conf";用 Python `zipfile.extractall` 重解压解决。Popen 的 cwd 必须是内层 `...\sqldeveloper\sqldeveloper`(bin 不存在)。
2. **首启弹窗两连**:①"从以前的安装导入首选项" → 点 否(约 1163,734);②"使用情况跟踪" → 点 确定(约 1103,604)。之后 win+up 最大化。
3. **`clip` 未注入**:script 环境没有 `clip`(与文档出入),用 `set_clip(text)` + `pyautogui.hotkey("ctrl","v")`。
4. **push 上传到 `<AUTO>/scripts/`**:脚本里 open 文件要用 `C:\Users\master\ptauto\scripts\<name>`,不是 ptauto 根。
5. **数据页签工具栏坐标(y=143)**:编辑370 / 取消编辑395(蓝箭头) / 添加行407(绿+) / 删除行437(灰X) / 提交458 / 回滚490。添加行后新行在原最后一行下一格(约 y=267+行高21×新增数),**先 shot 确认行号再点单元格**,别凭旧 y 猜——曾把值粘错行。
6. **未提交编辑污染**:粘贴错行后先点"取消编辑"(395),弹"是否保存更改"点 否;若切标签也弹同款对话框,点 否 会连同丢弃标签内容(工作表 tab 会被关掉,重开:右键连接 → 打开 SQL 工作表)。
7. **标签切换点击易失效**:点标签(y≈99)后必须 shot 验证真切换了;(573,99) 一带是 DEPARTMENTS 标签的 X 附近,点偏=关标签。
8. **工作表运行**:运行语句(单语句出查询结果网格)= 绿三角(359,122) 或焦点在工作表时 Ctrl+Enter(更稳);运行脚本(F5,输出到脚本输出)=(382,122)。粘贴大脚本后网格/脚本输出在下半屏,拖分割条(drag 385,848→385,420)可放大输出区。
9. **中文与字符集**:工作表/剪贴板粘贴中文无损;但 sqlplus 命令行跑 .sql 文件必须 `export NLS_LANG=AMERICAN_AMERICA.AL32UTF8`,否则 GBK 读 UTF-8 报 ORA-01756。表必须建在指定 schema(带 `yggl.` 前缀),否则落到 SYSTEM。
10. **后台进程**:SSH(Git Bash)里 `nohup ... &` 会被 ssh-skill 会话结束杀掉;起 GUI/长任务一律走驱动脚本(桌面会话)或 PowerShell `Start-Process`。`/F` 之类开关经 ssh 会被 MSYS 转路径 → `MSYS_NO_PATHCONV=1` 或 cmd /c 包裹。
11. **启动弹窗每次都重现(2026-11-06 实验2实战)**:上次点掉的"使用情况跟踪"遥测框这次开机又弹(点 确定 不会持久化设置);展开带保存口令的连接也可能弹"连接信息-[YGGL]"密码框(密码持久化不可靠)。**启动序列固定**:关遥测框(1103,604)→最大化→展开连接→遇密码框 paste_at(1000,525,密码)+确定(985,557)。别假设"上次处理过这次就没有"。
12. **树行 y 必须现算**:连接树行号与上次记忆可差 20px+(YGGL 实际 y≈168,按记忆 193 点会点中"数据库方案服务连接")。动手前 crop 放大读行位置(navicat #4 同族)。
13. **右键菜单跨轮存活(公#18 的 app 例外)**:树节点右键菜单(如 视图→新建视图(V))弹出后,跨多个驱动轮次仍停在屏幕上,下一轮直接点菜单项坐标成功(2026-11-06 三轮验证)。菜单项助记是 **V**(新建视图(V)),按 N 无反应。先 rclick+shot 取证,菜单项坐标(如 135,217)下一轮点;若哪次没存活再 esc 重来。
