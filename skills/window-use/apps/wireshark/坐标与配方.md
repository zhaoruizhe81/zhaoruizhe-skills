## 二、抓 TCP 踪迹配方（无人值守，全部可在桥 script 通道跑）

```python
import subprocess, time, socket, os
ip = socket.gethostbyname("dldir1.qq.com")          # 目标域名先解析
pc = r"C:\Users\lenovo\ptauto\tcp_trace.pcapng"
dc = subprocess.Popen([r"C:\Program Files\Wireshark\dumpcap.exe",
    "-i", r"\Device\NPF_{7478F10D-6BBF-4866-8F21-584AB1269171}",   # tshark -D 查到的接口
    "-f", "host " + ip + " and tcp", "-w", pc])
time.sleep(4)                                        # 等抓包就绪
r = subprocess.run(["curl","-4","--max-time","22","-sS","-L","-o","NUL",
    "-w","code=%{http_code} bytes=%{size_download} ip=%{remote_ip}",
    "http://dldir1.qq.com/weixin/Windows/WeChatSetup.exe"],   # 283MB 纯 HTTP 大文件
    capture_output=True, text=True, errors="replace")
log("curl rc=%s %s" % (r.returncode, r.stdout))
time.sleep(2)
subprocess.run(["taskkill","/F","/IM","dumpcap.exe"], capture_output=True)
log("pcap size " + str(os.path.getsize(pc)))
```

要点：
- **curl 必须加 `-4`**：坑见 踩坑.md **W2**（走 IPv6 时捕获过滤器全漏 → pcap 0 字节）。
- 下载源要选**纯 HTTP 大文件**（dldir1.qq.com 的 WeChatSetup.exe 实测 22s 拉下 67MB；
  很多老 URL 已下架，抓包前先 `curl -sSI` 探 Content-Length）。
- 验收：curl 的 `-w` 里 `remote_ip` 必须与捕获过滤器 host 一致，且 pcap size 明显 >0。

## 三、tshark 分析配方（回答 Wireshark Lab 思考题的四条命令）

注意：**subprocess 用 capture_output 字节模式 + 手动 decode**，`text=True` 在部分环境
stdout 返回 None 会炸拼接；中文字段用 `.decode("gbk","replace")`。

```python
TS = r"C:\Program Files\Wireshark\tshark.exe"; PC = r"C:\Users\lenovo\ptauto\tcp_trace.pcapng"
def t(*a):
    r = subprocess.run([TS,"-r",PC]+list(a), capture_output=True)
    return (r.stdout or b"").decode("utf-8","replace")

# Q3/Q1: SYN / SYNACK（raw 序号、确认号、端口）
t("-Y","tcp.flags.syn==1 && tcp.flags.ack==0","-T","fields",
  "-e","frame.number","-e","ip.src","-e","tcp.srcport","-e","tcp.dstport","-e","tcp.seq_raw")
t("-Y","tcp.flags.syn==1 && tcp.flags.ack==1","-T","fields",
  "-e","ip.src","-e","tcp.seq_raw","-e","tcp.ack_raw","-e","tcp.flags")
# 前N个报文段长度（帧长 ip.len / TCP载荷 tcp.len）
t("-Y","tcp.stream==0","-c","10","-T","fields",
  "-e","frame.number","-e","ip.len","-e","tcp.len","-e","tcp.flags.str","-e","tcp.seq","-e","tcp.ack")
# 质量统计 + 会话表
for f in ["tcp.analysis.retransmission","tcp.analysis.duplicate_ack","tcp.analysis.out-of-order","tcp.analysis.lost_segment"]:
    t("-Y",f,"-T","fields","-e","frame.number")
t("-q","-z","conv,tcp")
```
