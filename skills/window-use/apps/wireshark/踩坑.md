# Wireshark 私有坑（公共坑见根目录 踩坑清单.md，远程坑见 remote/远程坑.md）

拆自本包 坐标与配方.md（2026-11-05 win135 计网实验「用 Wireshark 分析 TCP」实战）。
环境：win135（1920×1080，Win11 精简版，Wireshark 4.7.4 中文界面，Npcap 1.90 已装）。
每条都是 症状 → 原因 → 解法。

## W1. Qt 菜单 UIA 枚举不到 MenuItem（popup #32768 不出现）+ 实测跨轮存活
- **症状**：UIA 枚举不到 Wireshark 的 Qt 菜单——popup #32768 不出现，MenuItem 列表为空，
  按菜单名/菜单项名驱动全部落空。
- **原因**：Wireshark 是 Qt 程序，菜单弹出层不是标准 #32768 popup 窗口，UIA 树里拿不到
  MenuItem，"按名点菜单"这条路在该应用不存在。
- **解法**：放弃 UIA，菜单导航只能 **shot 读坐标点菜单**。多级菜单可拆两轮：
  第一轮开菜单+截图，第二轮按截图坐标点子菜单。**跨轮存活的例外说明**：实测 Wireshark
  菜单**跨驱动轮次存活**（统计菜单开着隔了 2 轮还能点子菜单），与公#18/公#30
  "菜单生命周期=一个驱动轮次、开菜单→点菜单项必须同轮原子化"的结论相反——
  在本应用别机械套用原子化铁律，但点前仍以最新截图核对为准。

## W2. dumpcap 抓包 0 字节/curl 漏包：curl 走了 IPv6
- **症状**：dumpcap 挂着捕获过滤器抓包，curl 却拉不到流量进 pcap：pcap 0 字节/几乎没包。
- **原因**：curl 默认走 IPv6，而捕获过滤器写的是 `host <IPv4>`，IPv6 流量全被过滤器漏掉
  （公S7 附带坑）。
- **解法**：curl 加 **`-4` 强制 IPv4**；验收用 `-w %{remote_ip}` 核对——remote_ip 必须与
  捕获过滤器 host 一致，且 pcap size 明显 >0。

## W3. 模板表格 cells[2] 是标签不是数据行
- **症状**：python-docx 往报告模板表格 setcell(cells[2]) 写值，把「学生姓名：」「班级：」
  这些标签覆盖成了值。
- **原因**：该模板表格一行装两组"标签|值"：值在 **cells[1]/cells[3]**，cells[2] 是右侧
  另一对的**标签本身**（标签与值住在同一行相邻单元格），不是数据行。
- **解法**：值只写 cells[1]/cells[3]，别动 cells[2]。

## W4. Npcap/WinPcap 环境（主体见公S7）
- **症状**：老机器常有 WinPcap 残留，新版 Wireshark 报 "Unable to load Npcap (wpcap.dll)"。
- **原因**：WinPcap 未卸载/Npcap 未正确安装，wpcap.dll 加载失败。
- **解法**：卸载 WinPcap + 装 Npcap 的完整流程见 踩坑清单.md **公S7**（免费版 Npcap
  不支持 /S，必须 GUI 点装）。wireshark 特有事实：装完**无需重启**，`tshark -D` 能列出
  `\Device\NPF_{...}` 接口即 OK；dumpcap `-i` 用该 NPF 全名（win135 实测接口编号见
  本包 坐标与配方.md 一）。
