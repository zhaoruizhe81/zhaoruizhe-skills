## 配方一：AI 生成内容并采纳（五步主流程）

1. **框架**：帮我写 → 粘提示词（主题+4模块+每模块一段话）→ 发送 → 等 ✓完成（30~60s）→ 采纳
2. **细化**：三连击选中目标段 `pyautogui.click(x,y,clicks=3)` → **同一脚本内**点功能区帮我写 → 粘细化提示词 → 发送 → 采纳。⚠️ 光标/选区会决定 AI 插入点，别落在标题字符中间（会把标题劈成两半）
3. **表格类**（时间表/预算表）：光标放目标位置后的**正文空段落**（勿放标题上）→ 帮我写 → 提示词写明列名与限额 → 发送 → 采纳
4. **校对/合规**：文档问答侧边栏 + 提示词，回复在侧边栏不碰文档（AI校对/纠错按钮是会员功能）
5. **保存**：关掉所有对话框后 Ctrl+S → 远端 `ls -la` 验证 mtime

## 配方二：python-docx 往返修文本（GUI 修文本翻车两次后的标准路线）

```
WPS: 关全部对话框 → Ctrl+S → 远端 ls 验证 mtime → Ctrl+W 关文档
     （有未保存改动会弹"是否保存"：按需选 不保存(N)(1004,535)）
Mac: ssh_skill download windowpc ptauto/tmp.docx 本地.docx
     python-docx 改（拆段/删段/样式/插题注，确定性）
     ssh_skill upload windowpc 本地_fixed.docx ptauto/push.docx
远端: cd ~/Desktop && for f in [!~]*.docx; do cp /c/Users/master/ptauto/push.docx "$f"; done
     （[!~] 排除 ~$ 锁文件；循环借用原文件名免输中文）
WPS: 最近列表双击文件名重开（第一次 dclick 只会选中行，点文件名文本才打开）
```
⚠️ 推回覆盖前必须先关 WPS 里的旧文档，否则内存版会把修复版冲掉。
